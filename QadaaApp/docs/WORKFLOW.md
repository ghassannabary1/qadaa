# Qadaa Workflow

Use this structure when organizing work:

## Feature request
- decide if it belongs in MVP, Next, or Later
- add a task to TASKS.md

## Bug report
- add it to BUGS.md with severity and repro steps
- if urgent, move related work to top priority

## Design issue
- capture it in TASKS.md
- ask UX agent to review if needed

## Completion
- move finished tasks to Done
- keep docs tidy and current
