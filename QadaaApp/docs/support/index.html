Qadaa Support

Support page for QadaaApp

QadaaApp helps you track missed prayers in a simple and organized way. If you need help with the app, account access, reminders, or backups, you can contact us using the details below.

QadaaApp is a tracking tool and does not replace personal advice from a qualified scholar for religious questions.

How We Can Help

  • Questions about using QadaaApp features.
  • Help with reminders, sign-in, backup, or restore.
  • Bug reports and general support requests.

صفحة الدعم الخاصة بتطبيق QadaaApp

يساعدك تطبيق QadaaApp على تتبع الصلوات الفائتة بطريقة بسيطة ومنظمة. إذا كنت بحاجة إلى مساعدة بخصوص التطبيق أو تسجيل الدخول أو التنبيهات أو النسخ الاحتياطي، يمكنك التواصل معنا من خلال المعلومات التالية.

تطبيق QadaaApp أداة متابعة وتنظيم، ولا يغني عن استشارة عالم مؤهل في المسائل الشرعية.

كيف يمكننا مساعدتك

  • الإجابة عن الأسئلة المتعلقة باستخدام ميزات التطبيق.
  • المساعدة في التنبيهات أو تسجيل الدخول أو النسخ الاحتياطي أو الاستعادة.
  • استقبال بلاغات الأخطاء وطلبات الدعم العامة.
