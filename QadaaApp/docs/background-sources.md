# Islamic Floral Background Sources

## Goal

Collect internet sources specifically for the Islamic floral background direction of Qadaa.

Priority order:
- usable vector backgrounds
- open / public-domain sources
- museum references for motif accuracy
- photo references only for mood, not direct wallpaper use

## Recommendation

If we stay focused on the Islamic floral background only, the best next direction is:

1. Use museum references for motif truth:
- Dome of the Rock interior
- Iznik floral tiles

2. Use editable vector sources for actual design work:
- PublicDomainVectors
- Pixabay SVGs

3. Build one app-safe background family from that:
- header-only floral veil
- one medallion-backed hero
- one tiny floral divider accent

## What To Avoid

- full-screen photo backgrounds
- dense wallpaper behind text-heavy content
- direct copy of one museum artwork
- saturated gold-and-blue full mosaic fills
- using multiple floral styles at once
