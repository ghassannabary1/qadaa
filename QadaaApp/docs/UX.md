# Qadaa UX Principles

## Core UX goal
The app should feel calm, obvious, and fast.

## What success looks like
- user opens app and immediately understands progress
- adding one completed qadaa prayer takes one tap
- user does not need to read long explanations
- important numbers feel trustworthy

## Avoid
- cluttered dashboards
- too many fiqh options on first use
- heavy setup before first value
- guilt-heavy language

## Tone
- respectful
- clear
- calm
- encouraging, not preachy
