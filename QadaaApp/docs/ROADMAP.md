# Qadaa Roadmap

## Vision

Build a simple mobile app that helps Muslims track qadaa prayers clearly and consistently, without clutter.

## Product principles
- simple first
- trustworthy counts
- low-friction daily use
- Shafi‘i-aware, but not overwhelming
- local-first MVP

## Milestones

### MVP
- prayer backlog setup
- quick add for five daily prayers
- remaining/completed/today summary
- local persistence
- notes field

### Next
- onboarding flow
- better visual hierarchy
- history/log of completed qadaa
- export/backup

### Later
- Witr support
- smarter backlog estimation
- streaks and targets
- optional sync
- deeper madhhab settings
